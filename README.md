# LeetCode JS

Mis soluciones a problemas de [LeetCode](https://leetcode.com/) resueltos en **JavaScript**, organizados por patrón. El objetivo es practicar estructuras de datos y algoritmos, y dejar documentado cómo pienso cada problema.

Cada archivo incluye la dificultad, el patrón usado, la complejidad en notación Big O y una explicación de la idea en mis propias palabras.

## Estructura

```
leetcode-js/
├── README.md
├── arrays-hashing/
├── two-pointers/
├── sliding-window/
├── stack/
├── binary-search/
└── ...
```

Las carpetas siguen los temas de [NeetCode 150](https://neetcode.io/practice).

## Cómo ejecutar los tests

```bash
npm install
npm test
```
